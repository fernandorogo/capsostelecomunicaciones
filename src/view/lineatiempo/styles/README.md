# Estilos de Lineatiempo

`Lineatiempo.css` es el único CSS que debe importar la página.

Orden de carga:

1. `base.css`
2. `hero.css`
3. `navigation.css`
4. `section-heading.css`
5. `history.css`
6. `about.css`
7. `principles.css`
8. `quality.css`
9. `projection.css`
10. `footer.css`
11. `responsive.css`
12. `accessibility.css`

El footer usa `.inet-final` y mantiene el CSS solicitado. Sus adaptaciones responsive específicas están dentro de `footer.css`; no deben duplicarse en `responsive.css`.
